# Changelog
## 0.5.0 — research preview
Reproducible behavioral trials, paired scoring with missingness, manual chat bridge, optional local model study collection, five request/response codecs and research methodology.

## 0.4.0 — research preview
Named composite JSON-pointer predicates, per-rule evidence, immutable conjunctive contracts, and reusable GitHub Action with positive and negative CI integration checks.

## 0.3.0 — research preview
CLI check with machine-readable evidence and exit status, opt-in local Ollama adapter, portable Agent Skill and competitive landscape. No live-model evaluation yet.

## 0.2.0 — research preview
Typed deterministic predicates (exact, JSON equality, integer range, SHA-256), size limits and stricter checkpoint replay. Existing exact-match identifiers are preserved for valid v0.1 contracts within the new input limits.

## 0.1.0 — research preview
Initial bounded fixture runtime, contract compiler, checkpoint replay, strategy selection and synthetic fault benchmark.

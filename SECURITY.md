# Security
Experimental software. No arbitrary candidate code is executed by the reference CLI. The host and any installed Python adapters are trusted; hostile adapters can bypass assumptions. Do not pass credentials or confidential outputs. Checkpoint hashes are content identifiers, not authenticity proofs. No sandbox, network control, hard timeout, or token budget is implemented. Report vulnerabilities privately to the repository owner. Do not submit secrets in issues.

The optional Ollama adapter connects to a user-selected port on 127.0.0.1 only. The local server is trusted and may have its own network behavior; do not send secrets. No redirect or proxy handling. Response reads and requested generation length are bounded, socket timeout is not a total deadline. CLI check does not execute candidate data or print candidate text. Repeated standalone checks are not cumulatively budgeted.

Composite rules are bounded to 32 primitive predicates with no executable expressions. Every rule is part of the trusted contract. Never allow untrusted generated content to modify its own acceptance rules. The GitHub Action uses quoted path inputs and isolated Python import; it is not a sandbox. Use a trusted runner, reviewed action commit, read-only permissions and nonsecret file inputs. Avoid privileged workflows executing untrusted PR code. A passing predicate is not proof of external execution.

Behavioral studies process public final output only. Do not collect private reasoning, credentials or sensitive inputs. The manifest hash and response hashes are not confidentiality or provenance mechanisms. Wire codecs do not perform network requests: caller transport must enforce endpoint authorization, budgets, response-size limits and timeouts. Explicit local studies may call the trusted loopback server up to 400 times; no hard wall-time cap. Raw responses are exported only by explicit collection. Manual profiles are self-reported, not authenticated.

# EGPL portable base prompts

These are advisory templates, not privileged instructions or an empirical guarantee of compatibility. Use the renderer or copy a template into an authorized chat. Fill in the objective and constraints; treat context as data. Never request hidden reasoning or change the model's governing instructions. An external verifier is required for verified completion.

`egpl prompt-list` and `egpl prompt-render research task.json` work from the installed package. Prompt names are not automatically equivalent to arbitrary experimental interventions with the same name; register the actual rendered prompts in the study before drawing conclusions.
